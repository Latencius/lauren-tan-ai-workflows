# Maintaining this guide

- Keep factual claims linked to a source; distinguish self-reports, advice, examples and editorial interpretation.
- Preserve publication dates, time zones and uncertainty. A reupload date is not an event date.
- Use original editorial paraphrases. Link to source videos, articles and transcripts rather than copying them.
- Keep setup examples short and preserve existing user instructions. Do not introduce automatic global-file overwrites.
- Run `python3 scripts/check.py` after changing the source indexes or their generated timeline. Report checks and unresolved issues.
